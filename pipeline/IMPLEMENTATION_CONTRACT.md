# NSI and GARW Reimplementation Contract

## Status

This directory is a clean-room reconstruction from the manuscript text. It is not the missing original implementation. Every result generated by this code must be described as a reimplementation result and must carry the configuration hash, input-manifest hash, random seed, software versions, and model-weight identifiers.

## Sample and split unit

- The leakage-control unit is `group`, normally a scene. Pixels, keypoints, patches, or image pairs from one group may not occur in more than one split.
- A supplied `split` array is authoritative. Otherwise groups are assigned deterministically to an 8:1:1 train/validation/test split.
- Ridge hyperparameters are selected on validation groups, the probes are refitted on train plus validation groups, and final scores are evaluated only on test groups.

## Attribute accessibility A

- Features and every target channel are standardized with training-only statistics.
- Geometry and appearance use separate multi-output ridge probes.
- The held-out coefficient of determination is averaged uniformly across non-constant target channels.
- `A = (clip(R2_G, 0, 1) + clip(R2_A, 0, 1)) / 2`.

## Supervised subspace separation B

- Probe coefficient matrices in standardized feature coordinates are `W_G` and `W_A`.
- Raw supervised bases are `U_G = orth(W_G.T)` and `U_A_raw = orth(W_A.T)` under one fixed SVD rank rule.
- `OSR = ||U_G.T @ U_A_raw||_F^2 / min(k_G, k_A)` and `B = 1 - OSR`.
- OSR is measured before residualization. Residualizing first would force zero overlap by construction.
- GARW projection uses `U_A_perp = orth((I - U_G U_G.T) @ W_A.T)` and therefore remains distinct from the OSR measurement.

## Information purity C

- Dependence is estimated between held-out geometry- and appearance-probe outputs with the KSG-1 k-nearest-neighbor estimator in Chebyshev distance.
- The finite-sample estimator bias is estimated by permuting the appearance output with a fixed random seed. The dependence effect is `I_excess = max(I_observed - median(I_permuted), 0)` nats.
- The preregistered default bounded monotone transform is `C = 1 / (1 + I_excess)`.
- This transform is a reconstruction choice, not a recovered claim about the missing code. It is dimensionless only because KSG is fixed to natural logarithms. Absolute values remain protocol-dependent; rank sensitivity must be reported.
- The output also records the raw KSG estimate, permutation median, and permutation p value so that the transform is auditable.

## NSI

- `NSI = A * B * C`.
- NSI is interpreted only as an ordinal diagnostic under the fixed protocol.
- `NSI = 0.5` is a descriptive operational reference. It is not a hypothesis-test cutoff or an estimator of residual entanglement.

## GARW

- Geometry and appearance similarities are computed after projection into `U_G` and `U_A_perp`.
- Both candidate feature vectors are standardized with the saved training-set feature mean and scale before these bases are applied. Projector artifacts store those arrays explicitly.
- `g = sigmoid(alpha * NSI_local + beta)` and `score = (1 - g) * s_G + g * s_A`; therefore `g=0` is geometry-only and `g=1` is appearance-only.
- Annotation-dependent window NSI is a calibration target only. In the non-oracle analysis, `NSI_local` is predicted from explicitly listed observable features by a ridge proxy selected with scene-group cross-validation. Calibration rows receive group-out-of-fold predictions; evaluation rows receive predictions from a model fitted on all calibration scenes. Passing evaluation annotations directly to the gate is permitted only in a separately labeled `oracle_annotation` run.
- `alpha` and `beta` are calibrated only on disjoint calibration groups.
- Calibration loss gives equal total weight to each scene, then each query within a scene, so scene size and candidate count do not determine the fitted gate.
- The reconstructed conflict penalty is explicitly empirical: `lambda * 4g(1-g) * abs(s_G-s_A)`. It is zero at either endpoint and largest when the gate is uncertain. `lambda` is selected on calibration groups and an ablation with `lambda=0` is mandatory.
- This penalty is a new, declared implementation choice. It is not attributed to the Neyman-Pearson derivation.

## Statistics

- Scene-level paired differences use 10,000 group-bootstrap replicates and a two-sided Wilcoxon signed-rank test.
- Separability-performance association uses Spearman correlation with group-bootstrap confidence intervals and a permutation p value.
- Sensitivity covers ridge lambda, subspace rank, KSG k, purity implementation, annotation source, dataset, seed, and OSR implementation.
- Model or layer rankings are compared with Kendall tau and Spearman rho; cardinal agreement is not assumed.
- The primary OSR is the mean squared principal cosine required by Eq. (4). Maximum squared principal cosine is implemented only as a labeled sensitivity variant. Information-purity sensitivity compares the reciprocal and exponential monotone transforms of the same bias-corrected KSG estimate.

## Prohibited shortcuts

- No test-group hyperparameter selection.
- No random pixel-level split across scenes.
- No use of residualized bases to measure OSR.
- No reuse of legacy NSI numbers.
- No substitution of synthetic smoke-test output for scientific results.
- No claim of a universal NSI scale, strict 0.5 boundary, or exact Neyman-Pearson optimality for GARW.
